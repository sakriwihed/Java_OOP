# Java_OOP

Problems I solved during my Computer Science studies at **TU Braunschweig**.
They cover: structs, pointers, dynamic memory, strings, arrays, sorting/searching and data structures.

| Problem | Description | Concepts |
|---|---|---|
| [BinaryTree](Java/BinaryTree) | Builds a binary tree; inorder, preorder, postorder traversal and height | recursion, trees |
| [Knapsack](Java/Knapsack) | Solves the 0/1 knapsack problem | recursion, dynamic programming |
| [Temperature](Java/Temperature) | Temperature class with conversions | OOP, packages |
| [MatrixOperations](Java/MatrixOperations) | Matrix transpose and multiplication | 2D arrays |

## How to run
```bash
javac *.java
java Main
```
